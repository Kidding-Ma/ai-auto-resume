# 材料怎么放？

直接把已有材料放在 AI 当前打开的文件夹里。已有子文件夹也可以，不用移动、不用改名、不用重新排版。

| 材料 | 有什么帮助 |
| --- | --- |
| 旧简历 PDF / Word | 提取教育、经历和联系方式 |
| 项目说明 / 实习笔记 / 周报 | 找到你做过的具体事情 |
| 招聘要求（JD） | 判断应该突出什么 |
| 论文 / 获奖记录 | 补充研究经历和获奖情况 |
| 项目代码路径 / GitHub 链接 | 查清项目做了什么、哪些部分是你做的 |

想加照片，把用于简历的照片一起放进工作区即可，JPG 或 PNG 都可以。有多张照片时，说清楚用哪张；没有照片不影响生成。

先写教育经历和自己做过的事情。有目标岗位或招聘要求可以一起放，没有也能生成。姓名和联系方式可以最后补充；缺少时先生成不含联系信息的草稿。

Word 推荐 .docx；扫描 PDF、截图和旧 .doc 可能需要识别图片文字或转换格式，能否处理取决于你使用的 AI 助手。AI 必须告诉你哪些文件没读成功。

没旧简历？新建 `个人情况.txt`，先用自己的话写：

```text
教育：学校、专业、学历、入学和毕业时间
经历：实习、课程作业、比赛、社团或其他做过的事情
我做了什么：自己负责哪一部分，怎么做的，有什么结果
技能：学过什么、实际用过什么
姓名和联系方式：可以最后再补
```

没有实习或项目可以留空。课程作业、毕业设计、兼职和志愿活动也可以提供，由 AI 判断哪些适合写进简历；没有结果数字就不填。不要把示例当成自己的经历。

不要放密码、密钥、身份证号码、银行卡信息或未获准分享的公司源码。AI 只应处理你明确提供的材料；云端模型的内容处理规则取决于所用服务。
