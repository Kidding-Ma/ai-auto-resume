# 材料怎么放？

把已有材料放进 materials/，不必重新排版，也不必按固定名字命名。

| 材料 | 有什么帮助 |
| --- | --- |
| 旧简历 PDF / Word | 提取教育、经历和联系方式 |
| 项目说明 / 实习笔记 / 周报 | 找到你做过的具体事情 |
| 招聘要求（JD） | 判断应该突出什么 |
| 论文 / 获奖记录 | 补充研究经历和获奖情况 |
| 项目代码路径 / GitHub 链接 | 查清项目做了什么、哪些部分是你做的 |

建议先提供：教育经历、一段项目或工作经历、目标岗位。姓名和联系方式可以最后补充；缺少时先生成不含联系信息的草稿。

Word 推荐 .docx；扫描 PDF、截图和旧 .doc 可能需要识别图片文字或转换格式，能否处理取决于你使用的 AI 助手。AI 必须告诉你哪些文件没读成功。

没旧简历？新建一个 .txt 文件，随便写清楚这些就可以：

```text
想投：什么岗位，哪个城市
教育：学校、专业、学历、入学和毕业时间
经历：在哪做了什么，自己具体负责什么
项目：解决什么问题，怎么做的，结果有什么依据
技能：实际用过什么，能做到什么程度
```

不要放密码、密钥、身份证号码、银行卡信息或未获准分享的公司源码。AI 只应处理你明确提供的材料；云端模型的内容处理规则取决于所用服务。
