# 遇到问题

**我还没有简历草稿，能用吗？**

能。新建 `个人情况.txt`，写清想投的岗位、教育经历、做过的事情和技能即可。[照着填写](materials.md)。没有实习或项目可以留空，先写真实情况。

**只把 GitHub 链接发给 AI 就行吗？**

链接告诉 AI 怎么做，材料告诉它你做过什么。把材料放在当前工作区，再把项目链接和目标岗位交给能操作本地文件的 AI 助手。只有聊天功能时，需要你粘贴或上传材料。还需要自己保存 AI 写好的代码并编译 PDF。

**DSH、OpenCode 搭配 DeepSeek 可以吗？**

这类能读取文件、运行命令的助手使用首页的同一段提示词。无需换模型，也无需单独安装 skill；提示词会让它读取项目指引。具体能否读出某种材料、编译 PDF，还要由助手检查当前工具和权限。

**我不会 LaTeX，能用吗？**

能。能操作本地文件的 AI 可以写内容、改排版并生成 PDF；只有聊天功能时，需要自己保存代码并编译。最后自己核对经历和个人信息。

**我已经装了 LaTeX，还要装 MiKTeX 吗？**

不用。先让 AI 用现有环境编译示例。缺少组件就补组件，不必再装一套。[具体检查方法](setup.md)

**VS Code 已有插件，还要再装吗？**

不用。已有插件能编译和预览就直接用，也不用覆盖已有配置。AI 通过命令生成 PDF 时不需要编辑器插件。

**提示找不到 xelatex，怎么办？**

让 AI 先检查是否已经安装、程序路径是否能找到。确认没有可用的 XeLaTeX 时，再按[准备教程](setup.md)补齐。

**为什么第一次生成 PDF 很慢？**

可能在下载缺少的字体或排版组件。使用 MiKTeX 时，确认联网并允许按需安装；其他 LaTeX 安装通过各自的工具补齐组件。下载失败时先检查网络和下载源。

**为什么提示需要 Perl？**

可能用了插件默认的编译方式。选择项目提供的 **XeLaTeX x2**，或让 AI 运行 `python scripts/resume.py build`，这套流程不需要 Perl。

**材料会上传到 GitHub 吗？**

项目不会自动上传。本仓库默认忽略新增文件，草稿和生成结果保存在 output 中；其他工作区的 Git 设置需要单独检查。但你主动强制添加文件或自行上传时，这个设置拦不住；公开前要检查文件列表。云端 AI 也可能接收它读取的材料，具体取决于你使用的服务。

**AI 为什么还会问我问题？**

它可能无法确定某段经历是不是你做的，或发现两份材料里的日期不一致。这些信息需要你确认，不能靠猜。材料不足时会先整理能确认的内容，并列出缺少什么。

**需要另外安装简历 skill 吗？**

不用，项目里已经包含。让 AI 按 `AGENTS.md` 阅读即可。

**生成的 PDF 可以直接投吗？**

先打开看一遍，核对姓名、联系方式、学历、日期、个人贡献和数据。再看 `output/review.md` 里有没有需要确认的内容。

**怎么加照片？**

把照片放进工作区，告诉 AI“加上这张照片”即可。AI 会复制照片并调整排版，不改原图；不提供照片也能正常生成。

**可以换模板吗？**

可以。把有明确开源许可的模板链接交给 AI，让它保留原作者和许可信息，再调整排版。
