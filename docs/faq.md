# 常见问题

**没有旧简历或实习经历，能用吗？**

能。新建 `个人情况.txt`，写清教育、做过的事情和技能即可。[照着填写](materials.md)。材料少也会先整理成可审阅的简历，没有的栏目可以留空。

**什么是工作区？**

就是 AI 助手当前打开的文件夹。把个人情况和材料放进去，再发首页提示词。不需要创建 materials 文件夹，也不要求填写目标岗位。

**一定要用 VS Code + Codex 吗？**

不用。这是推荐组合，OpenCode、DeepSeek Harness 等能读取本地文件、运行命令的助手也可以。都用同一段提示词。

**不会 LaTeX，需要额外安装简历技能吗？**

不需要自己写 LaTeX，也不用另外安装 skill 或 agent。让 AI 按项目指引写内容、使用模板并生成 PDF 即可。只有聊天功能的窗口需要手动提供材料和编译，不能仅凭链接自动操作电脑。

**已经装过 LaTeX、编辑器或插件，还需要安装吗？**

已有的能用就继续用。缺什么补什么，不必再装一套或覆盖配置。[工具检查说明](setup.md)。

**找不到 xelatex，或提示缺字体、Perl，怎么办？**

让 AI 先检查安装位置、路径和组件。项目提供的 XeLaTeX 编译方式不依赖 Perl；第一次编译可能需要下载缺少的字体或组件。[具体说明](setup.md)。

**材料和简历会上传到 GitHub 吗？**

项目不会自动上传。工具仓库只允许清单中的公开文件加入 Git，其他工作区的 Git 设置需要单独检查。强制添加文件或覆盖已跟踪文件时，忽略规则无法保护它们。使用云端 AI 时，读取内容可能发送给所选 AI 服务。

**怎么加照片？**

把照片一起放进工作区，有多张时说明用哪张。AI 会复制照片用于排版，保留原图；没有照片也可以生成。

**为什么 AI 还会问问题？**

两份材料的日期冲突、本人贡献不清楚等情况需要确认。材料能回答的不用再问；缺少非必要信息时先做出简历，不要求凑项目或数字。

**如何检查生成质量？**

AI 先核对事实、内容顺序和措辞，再编译并检查整页 PDF。脚本检查不能代替事实核对，投递前仍要检查姓名、联系方式、学历、日期和个人贡献。[写作与检查规则](writing-rules.md)。

**这份简历用什么模板？**

默认固定使用首页展示的 Overleaf 中文简历模板。修改内容、调整篇幅或添加照片时保持模板样式，不让 AI 自行换版式。[模板来源与调整](../THIRD_PARTY_NOTICES.md)。
