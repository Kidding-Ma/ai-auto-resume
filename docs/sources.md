# 写作方法参考

核对时间：2026-11-04。Star 数为当时的仓库总数，不是某个 skill 的使用量，也不代表写作效果保证。

| 来源 | 当时 Star 数 | 本项目采用的方法 |
| --- | ---: | --- |
| [Reactive Resume](https://github.com/reactive-resume/reactive-resume) | 45317 | resume-writer 的事实清单、按经历决定顺序、摘要需有实际价值；resume-bullet-writer 的具体行动和可证实结果、无需强求每条数字 |
| [ResumeSkills](https://github.com/Paramchoudhary/ResumeSkills) | 3026 | resume-bullet-writer 的动作、任务对象、做法与结果检查 |

这些写作方法已整理进[写作规则](writing-rules.md)，AI 会在生成简历前读取。使用者无需安装这两个项目。ResumeSkills 中“每条必须有数字”和无证据估算指标的建议不采用；Reactive Resume 的多轮访谈简化成最多一轮关键事实确认。MIT 许可保留在 licenses 中。

模板使用 [Overleaf Chinese Resume Template](https://cn.overleaf.com/latex/templates/chinese-resume-template-zhong-wen-jian-li-mo-ban/fbdypsjmgwbb)，作者 xiangrongjingujiu，页面许可 CC BY 4.0。保留原版 11pt A4、左右 0.7 英寸、上下 0.5 英寸及章节样式。原模板依赖的商业 Adobe 字体不随项目分发，以开源宋/黑体和 TeX Gyre Termes 替代；字形不承诺与 Adobe 字体逐像素一致。有照片时预留对称空间，确保姓名仍相对整页居中。

不采用编造项目或添加未使用技术的建议。公开示例只使用虚构信息。
