# 写作与检查规则

AI 在写简历前读取本页。规则只决定内容取舍，不允许换模板或重设计版式。

## 按材料自动选择顺序

- 在校生、应届生：教育经历 → 最有说服力的实习或项目 → 另一类经历 → 奖项 → 技能。实习很少、项目更强时，项目在前。
- 有连续工作经历：工作经历 → 代表项目 → 教育经历 → 技能与其他必要信息。
- 科研方向或科研材料占主导：教育 → 科研与论文 → 项目或实习 → 奖项 → 技能。不据此编造求职方向。
- 信息较少：教育 → 真实课程/实践/其他经历 → 技能。没有的栏目直接省略，不添加“暂无”，不捏造经历。
- 日期在每个经历栏目内倒序；最相关且有证据的经历优先占篇幅。高含金量且相关的竞赛奖项可提前，不能把每个小奖都放在项目前。
- 默认不写“个人概述”“自我评价”“个人优势”。只有用户要求，或转行等场景确实需要解释已有事实，才写两行以内且不复述正文。

## 把事情说清楚

每条写“本人做了什么 + 具体做法 + 可证实结果或完成的功能”，不是把 STAR 四个字当成四个小标题。通常一至两行，每段经历二至四条；材料少时一条也可以，材料多时按价值删减。

可以重组散乱材料、补清已有上下文、归纳技术难点、突出真实成果。不能把“学过”写成“熟练”，把课程作业改成企业实习，把团队成果都算个人贡献，把参与改成主导。没数字就写完成的功能、交付物或解决的问题，不估算好看的百分比。

删除“赋能、闭环、深度参与、全面提升、具有良好能力”等空话。动作要匹配贡献，不为了避免“参与”就夸成“独立负责”。项目类型写在标题右侧或日期旁，不在每一行后面补解释。

## 括号和奖项

- 不写连续括号、嵌套括号或整句括号补充。把有用的信息直接写进句子，其他说明删掉。
- 中文项目不逐项附英文翻译；缩写首次出现确有必要时才解释一次。正式赛事名、论文题目、学历状态和确有必要的缩写允许括号，不能机械删除正式名称中的括号。
- 奖项先写实际奖牌/等级，再写赛事、赛区，年份放最后或右侧。例如：**金奖**｜ICPC 亚洲区域赛·某赛区｜2025。不得将材料的“金牌”擅自改成官方称谓不同的“冠军”。
- 同一赛事重复奖项可合并，但必须保留赛区、年份和等级对应关系。默认按相关性、赛事级别和奖项等级排序，同等重要时年份倒序。无法判断赛事级别时保留原名，不凭印象排名。
- 不把论文的“第二作者”埋在括号里；直接写“第二作者，发表于……”。不添加“EI”等未证实标签。

## 材料少也先给成品

利用已有的课程设计、毕业设计、比赛、志愿或兼职记录，但不要推测没提供的活动。事实稀少时可以给半页或较疏的一页；保持模板字号、页边距、章节样式，不能放大字或重复经历凑满。禁止空泛概述、无依据的爱好、能力自评和星级进度条。缺姓名/联系方式时交付可审阅草稿，注明补充后再投，不保留假名字或占位符。

## 自动检查再交付

1. 对照材料检查姓名、学校、日期、奖项、数字与个人贡献；矛盾不偷偷择一。
2. 扫描括号：逐个判断是否必要，删掉解释性括号。确认奖项等级前置，个人概述默认已省略，栏目和日期顺序合理。
3. 检查模板：保持锁定的 resume.cls、字体层级、字号、页边距和横线；仅改 resume.tex 正文及已有照片开关。
4. 编译并查看整页 PDF：姓名相对页面中心居中，有/无照片均如此；照片不压文字；无缺字、溢出、裁切、异常大空白。不能仅以编译退出码为成功依据。
5. PDF 不超过一页是默认目标，不是压缩到不可读的理由。内容确实需要两页时按用户要求处理，未指定就优先删重复内容。
6. 默认只交付 PDF、tex 与少量待确认事实；内部选择记录保存在 output/.work，不让用户先读报告。
